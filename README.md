# Site vitrine HTML / CSS / JS

Mini site vitrine multi-pages réalisé dans le cadre de ma reconversion vers le développement web full stack. Ce projet m'a permis de m'entraîner sur les bases du front-end : structuration du contenu, mise en forme, et ajout d'interactivité.

## 🔗 Démo en ligne

👉 [Voir le site en ligne](#) *(lien à ajouter une fois déployé sur GitHub Pages)*

## 📄 Pages du site

- **Accueil** — page de présentation avec un bouton interactif
- **À propos** — présentation de ma démarche et de mes objectifs
- **Contact** — formulaire de contact (nom, email, message)

## 🛠️ Technologies utilisées

- **HTML5** — structure sémantique des pages
- **CSS3** — mise en forme, navigation, style du formulaire
- **JavaScript** — interactivité (fonction déclenchée au clic sur un bouton)

## 🚀 Lancer le projet en local

1. Cloner le repo :
   ```bash
   git clone https://github.com/ton-pseudo/site-vitrine-html-css-js.git
   ```
2. Ouvrir le fichier `index.html` dans un navigateur (aucune installation nécessaire).

## 📌 Objectif du projet

Premier projet concret réalisé en autoformation, pour valider mes bases en HTML/CSS/JS avant d'intégrer une formation de développeur web full stack.
